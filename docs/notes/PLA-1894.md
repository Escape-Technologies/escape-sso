# PLA-1894 notes

- `validateConfig(input: unknown)` returns `{ ok, config }` with every default filled in and `allowedDomains` lower-cased. Errors name the field only. Allowed domains must contain a dot (`localhost` is rejected).
- `publicPaths` entries must start with `/` and contain no `*`. `oidc-flow` matches them exactly.
- `configFromEnv(env)` returns a raw record for `validateConfig`; a non-numeric `SSO_SESSION_TTL_SECONDS` is passed through as a string so validation rejects it.
- Times are Unix seconds. `now` defaults to the current time on every function and tests inject it.
- `signSession` and `signPending` throw on an invalid config. `readSession` and `readPending` return `null` and never throw.
- Session `exp` is clamped by validation to at most 28800 s. Pending login tokens live 600 s.
- Cookies: `serializeCookie` sets Secure unless `secure: false`. Use `requiresSecureCookie(requestUrl)` to decide, which is false only for plain-http localhost or 127.0.0.1. `clearCookie` takes the same `secure` option.
- `parseCookies` keeps the first of duplicate names and returns a null-prototype record.
- `src/core/index.ts` still exports only the `createSSO` stub. The new modules are not re-exported yet; `oidc-flow` wires them in.
