# PLA-1893 notes

- Keep platform-neutral authentication and session logic under `src/core/`; platform integrations live under `src/adapters/`.
- Put standard Node tests in `test/` and edge-runtime tests in `test/edge/`. Vitest runs these as separate `node` and `edge` projects.
- Package dependencies are pinned exactly. The package requires Node 20 or later for development and Node adapters; core and fetch code target Web-standard runtimes.
