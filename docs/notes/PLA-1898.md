# PLA-1898 notes

- `withSSO` returns `Promise<Response>`, keeps the native argument tuple, and exposes verified identity with `getUser(request)`.
- Workers env applies only when call has three arguments and argument three has `waitUntil`; other calls use `process.env`.
- Node adapters build bodyless gate requests and keep original `IncomingMessage` and `ServerResponse` for the app. `trustProxy` is opt-in.
- Node response conversion uses `Headers.getSetCookie()` to preserve each `Set-Cookie` field.
